Kütüphanem - Kişisel Kitap Listesi

React ile geliştirilmiş, okunacak ve okunmuş kitapların takip edilmesini sağlayan bir kütüphane web uygulaması.

Özellikler
Kitabın adı ve yazar bilgileriyle listeye kitap ekleme
Toplam, okunan ve kalan kitap sayılarını gösteren sayaçlar
Kitaplar içinde arama
Kitap okundu olarak işaretleme (okunan kitapların üstü çizili görünür)
Listeden kitap silme
Liste boşken ya da arama sonuç vermediğinde gösterge ekranı
Kullanılan Teknolojiler
React 19
Vite
Tailwind CSS
JavaScript (JSX)
ESLint
Kurulum ve çalışmama
Projeyi klonlayın:
bash
   git clone https://github.com/tugceyildizz2/kutuphane-projesi.git
Projeye girin:
bash
   cd kutuphane-projesi
Bağlantıları yükle:
bash
   npm install
Geliştirme sunucusunu almak:
bash
   npm run dev

Üretim derlemesi için npm run build, derlemeyi yerelde incelemek için npm run previewkomutlarını kullanabilirsiniz.
